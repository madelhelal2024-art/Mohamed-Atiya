# قالب تطبيق تعليمي عام — 3.0.0

قالب مستقل مشتق من أحدث نسخة مصدر تم التحقق منها بتاريخ **25 سبتمبر 2026**، وليس إعادة استخدام القالب القديم وحده. تمت إعادة استخدام الواجهات والوظائف الحديثة وتعميم ارتباطها بالمحتوى. تفاصيل النسخة الأصلية وحدود المطابقة في `SOURCE_VERSION.json` و`docs/RELEASE_NOTES.md`.

**ابدأ بملف `00-ابدأ-هنا.txt`.** للاستخدام مع مساعد برمجي، استخدم `01-أمر-تخصيص-القالب.txt` بعد رفع المشروع كاملًا.

## ما الموجود؟

واجهة عربية باتجاه RTL: الصفحة الرئيسية والهوية المحايدة، مناهج ومستويات ومجالات ووحدات ودروس، بحث وتصفية، فهرس تفصيلي تفاعلي، عرض مجمّع ومتتابع، شارات إنجاز ورسوم تقدم محلية، حركات ظهور وإكمال واحتفال وصوت نقرة. توجد صفحة برامج ومحاضرات، واستبيان تأملي للتعلم، وسبورة تعليمية متقدمة.

كل درس يحتفظ بتسعة أقسام: أهم النقاط، التلخيص والخرائط، الفيديو، الأنشطة، التقويم، البوكليت، العرض التقديمي، المساعد الموجّه، والواجبات والاختبارات. تبقى الأقسام ظاهرة حتى قبل إضافة المحتوى.

الهيكل الافتراضي **4 مستويات، 4 مجالات عامة، 8 وحدات، 24 خانة درس فارغة**. هذه عناوين تخطيطية وليست مواد مدرسية أو تخصصًا مفروضًا. يمكن تغيير العدد والتسميات من البيانات. لا يتضمن القالب اسمًا شخصيًا حقيقيًا أو صورة صاحب التطبيق السابق أو شعاره أو مواده أو روابط تواصله واشتراكه.

## التشغيل

يتطلب المشروع Node.js متوافقًا مع `engines` في `package.json`، وnpm واتصالًا لتنزيل المكتبات. الإصدارات المعلنة للمكتبات من نسخة المصدر المرجعية؛ لا يوجد ملف قفل مثبت لأن تثبيت المكتبات لم يكتمل في بيئة إعداد الحزمة.

```bash
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. لا تفتح `index.html` مباشرة بالنقر المزدوج؛ ملفات React وTypeScript تحتاج خادم التطوير أو البناء.

للفحص وبناء نسخة النشر:

```bash
npm run build
npm run preview
```

أمر البناء يشغّل التحقق من المحتوى والإعدادات وTypeScript واختبارات Vitest وفحص أنماط الأسرار، ثم Vite. بعد تثبيت ناجح احفظ `package-lock.json` مع المشروع. عندها يمكن استخدام `npm ci` في البيئة النظيفة. لا تتجاوز فشل الاختبارات بنشر نسخة لم تُفحص.

**حالة التحقق الحالية:** نجحت الفحوص المحددة في `VALIDATION_REPORT.md`. لم يُنفّذ هنا بناء إنتاج ناجح أو اختبار متصفح فعلي بسبب تعذر استكمال تنزيل المكتبات. وجود اختبارات في المشروع لا يعني أنها نُفذت كلها في هذه البيئة.

## النشر دون المساس بتطبيق سابق

أنشئ مستودع GitHub جديدًا. ارفع **محتويات** هذا المجلد بحيث يظهر `package.json` في جذر المستودع، بما فيها `.github` و`.gitignore`. لا ترفع ملف ZIP وحده باعتباره موقعًا، ولا ترفع `node_modules`.

يمكن ربط المستودع الجديد بمشروع استضافة جديد. إعداد Vercel مرفق: أمر البناء `npm run build` ومجلد الناتج `dist`. يوجد أيضًا ملف إعادة توجيه للاستضافة الثابتة. تستخدم المسارات `HashRouter`، مثل `/#/curriculum`.

عند النشر داخل مسار فرعي، اضبط `base` في Vite وراجع **كل** مسارات `/assets/` لتلائم المسار الفرعي؛ الإعداد الافتراضي هنا هو النشر على جذر النطاق. لا توجد عملية نشر تلقائي أو حساب استضافة مربوط داخل الحزمة. إجراء GitHub المرفق للفحص والبناء فقط.

## حدود مهمة

التقدم والشارات حفظ محلي في المتصفح، وليس سجلًا مركزيًا لطلاب الصف. إزالة بيانات الموقع تزيل هذا الحفظ. المحاكاة مميزة صراحةً وليست درجات حقيقية. وقت الدراسة الفعلي لا يُقاس.

السبورة تحفظ محليًا عبر IndexedDB وتسمح بتنزيل مشروعها وصورة PNG. لا تعتمد على الحفظ المحلي وحده؛ احتفظ بنسخة من ملف السبورة. الاستبيان أداة تأمل ذاتي، وليس اختبارًا مقننًا أو تشخيصًا لنمط تعلم ثابت.

المساعد محتوى موجّه معدّ مسبقًا؛ لا يستدعي نموذج ذكاء اصطناعي ولا يستهلك مفتاح API. روابط الفيديو والملفات قد تعتمد على خدماتها وصلاحيات المشاركة. «وصول مقيّد» في بطاقات البرنامج ليس حماية اشتراك. كل ما يُضمّن في تطبيق واجهة أمامية قد يصل إليه الزائر؛ لا تضع ملفات سرية أو مفاتيح وصول فيه.

لا تتضمن الحزمة ملفات خطوط. أسماء الخطوط في CSS تستخدم الخطوط المتاحة لدى المتصفح، وقد يختلف مظهر النص قليلًا عند غياب الخط المسمّى.
