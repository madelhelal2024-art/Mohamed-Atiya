# مميزات التطبيق التعليمي

- **واجهة عربية كاملة RTL** مع تصميم متجاوب لكافة الشاشات.
- **تدرج تعليمي واضح**: 4 مستويات، 8 وحدات، 24 درساً.
- **9 أقسام لكل درس**: أهم النقاط، التلخيص، الفيديو، الأنشطة، التقويم، البوكليت، العرض، المساعد الموجّه، الواجبات.
- **سبورة تفاعلية** تدعم أدوات الرسم والتصدير كصورة PNG وملف ملاحظات.
- **نظام شارات وأوسمة إنجاز** ومخططات تقدم باستخدام D3 وRecharts.
- **استبيان تأمل ذاتي** ومساعد تعليمي موجّه.
