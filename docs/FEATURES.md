# خريطة الخصائص والحدود

## واجهة المحتوى

الصفحة الرئيسية: هوية محايدة قابلة للاستبدال، مدخل المناهج، بطاقات الإنجاز، مدخل الاستبيان ومدخل السبورة، والتواصل بعد تهيئته. توجد ترويسة وتذييل وتنقل متجاوب.

المناهج: بحث عربي وكلمات وصول سريع، أغلفة، حالات تقدم وشارات. يمكن إظهار الفهرس التفصيلي من زر مخصص داخل صفحة المناهج. يعرض وحدات التطبيق الحالي بدل منهج ثابت.

الوحدة: شريط بصري ونسبة إنجاز، تصفية بالنوع والبحث، تقسيم الموضوعات أو القائمة المتتابعة، وأزرار إكمال.

الدرس: رأس بصري ومسار تنقل، رحلة التعلم، الأقسام التسعة القابلة للفتح والطي، موارد صوت وصور وفيديو وملفات، السابق والتالي، وتحديد الاكتمال أو إلغائه.

## الإنجاز والحركة

حفظ تقدم محلي، شارات تراكمية، إشعار اكتساب الشارة، دوائر D3 متحركة، مخطط Recharts لآخر سبعة أيام، ظهور متتابع للعناصر، نبضة زر الإكمال، علامة نجاح وصوت Web Audio واحتفال جسيمي. يوجد احترام لتفضيل تقليل الحركة حيث طُبق في المكونات والأنماط.

تقدم المتصفح مستمد من تحديد الدروس يدويًا كمكتملة؛ ليس قياسًا آليًا لفهم المتعلم. المحاكاة خيار تعليمي منفصل معلن. لا توجد درجات مركزية أو بيانات صف حقيقية أو تسجيل لوقت الدراسة الفعلي.

## السبورة التعليمية

قلم وتظليل وممحاة تحذف الضربة، نص عربي وصور نقطية محلية، أشكال وأسهم وخطوط، تحديد وتحريك وتغيير الحجم والتدوير وقفل العناصر، تراجع وإعادة، خلفيات متعددة وشبكات، تكبير وتصغير، ملء الشاشة ووضع عرض مع قفل، ليزر، كشاف تركيز، ستارة، مؤقت وعدّاد وقت، عبارات تشجيع وعدّاد نجوم، مسطرة ومنقلة قابلتان للتحريك والتدوير، وآلة حاسبة.

الحفظ عبر IndexedDB محليًا. يمكن تنزيل ملف المشروع بامتداد `.utbboard` وإعادة فتحه، وتصدير PNG. السبورة صفحة عمل واحدة؛ لا توجد إدارة صفحات متعددة أو تصدير PDF أصلي. المسطرة والمنقلة وسائل بصرية وليستا أداة قياس مادي معايرة.

## الاستبيان والبرامج

استبيان من 30 سؤالًا مع تقدم مرئي ونتائج وخطة أسبوعية ونصائح عامة. نتائجه مبنية على إجابات المستخدم، وليست تشخيصًا أو اختبارًا مقننًا.

صفحة البرامج تحتفظ ببطاقات المحاضرات والتسجيل والمادة العلمية. الأسعار والروابط في القالب غير مفعلة. الوسم البصري للمحتوى المقيد لا ينفّذ حماية أو إدارة اشتراك.

## لا يتضمن

تسجيل دخول، قاعدة بيانات طلاب، لوحة إدارة خلفية، LMS، دفع إلكتروني، نشر تلقائي، ذكاء اصطناعي متصل بمفتاح، حماية تنزيل حقيقية، أو تحليلات زيارات خفية. هذه وظائف جديدة تتطلب تكليفًا وتصميمًا مستقلين.
