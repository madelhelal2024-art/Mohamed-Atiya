# إضافة ملفات دروس اللغة العربية — الصف السادس الابتدائي

يظهر في التطبيق قسمان مستقلان: الفصل الدراسي الأول (الفهرس متاح)، والفصل الدراسي الثاني (ينتظر فهرسه).
تم حذف أرقام الصفحات من بيانات الفهرس وعرضه. تُعرض عناوين الوحدات والموضوعات فقط.

## أقسام كل درس

| مفتاح القسم في البيانات | عنوانه في التطبيق |
| --- | --- |
| `keyPoints` | أهم النقاط |
| `summary` | التلخيص والخرائط |
| `video` | شرح الفيديو |
| `activities` | الأنشطة التطبيقية |
| `quiz` | التقويم الذاتي |
| `booklet` | البوكليت والمذكرة |
| `presentation` | العرض التقديمي |
| `assistant` | اسألني وأنا هشرح لك |
| `homework` | الواجبات والاختبارات |

## آلية إضافة ملف

1. افتح `src/data/grade-six-term-one-index.json` وحدد `unit.id` ورقم ترتيب العنوان (بدءًا من 1).
2. ضع الملف في `public/assets/lessons/grade-six/term-one/<unit-id>/<رقم العنوان من خانتين>/<section-key>/`؛ مثل `public/assets/lessons/grade-six/term-one/self-development/01/keyPoints/main.pdf`.
3. أضف رابطه إلى `src/data/grade-six-lesson-files.json` تحت مفتاح `unit-id/01`. يبدأ رابط الملف المحلي بـ `/assets/lessons/grade-six/`؛ ويمكن بدلًا منه استخدام رابط HTTPS آمن لمصدر فيديو أو مورد خارجي.

مثال **توضيحي فقط**، لا يُنسخ إلى بيانات الإنتاج إلا بعد رفع الملف فعليًا:

```json
{
  "self-development/01": {
    "keyPoints": [
      {
        "title": "ملف أهم النقاط",
        "url": "/assets/lessons/grade-six/term-one/self-development/01/keyPoints/main.pdf"
      }
    ]
  }
}
```

يمكن إضافة أكثر من ملف إلى القسم نفسه. تظهر الأقسام التسعة دائمًا، لكن الأقسام التي بلا مواد تُعرض بوضوح باعتبارها «بانتظار الملفات»، وليس محتوىً جاهزًا.

**تنبيه:** قسم «اسألني وأنا هشرح لك» مُجهّز حاليًا لعرض مواده الموثّقة، وليس متصلًا بخدمة ذكاء اصطناعي خارجية. لا تُرفع ملفات شخصية للطلاب، ولا ملفات محمية بحقوق نشر دون ترخيص مناسب.
