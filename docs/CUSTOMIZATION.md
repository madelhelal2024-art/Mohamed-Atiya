# دليل التخصيص

## الخطوات الأساسية:
1. **تحديث هوية المعلم**: عدّل `src/data/teacher.json` وضع شعارك في `public/assets/brand/`.
2. **ضبط إعدادات القالب**: عدّل `src/data/template-settings.json` وغيّر `storageNamespace`.
3. **تحديث المنهج**: عدّل `src/data/curriculum.json` و`src/data/unit-index.json`.
4. **تحديث محتوى الدروس**: عدّل الملفات المقابلة في `src/data/lessons/lesson-XX.json`.
5. **البرامج والاشتراكات**: عدّل `src/data/student-programs.json`.
