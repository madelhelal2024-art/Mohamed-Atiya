# ملفات دروس الصف السادس

مجلد الفصول والدروس. انظر `docs/GRADE_SIX_CONTENT_GUIDE.md` في أصل المشروع.

- الفصل الأول: `term-one/<unit-id>/<entry-number>/<section-key>/<filename>`.
- مثال: `term-one/self-development/01/keyPoints/main.pdf`.
- درس «كنز لا يُقدَّر بثمن»: `term-one/self-development/02/` ويضم `summary/` و`video/` و`booklet/`.
- لا تُنشأ روابط ظاهرة للطلاب قبل وجود ملفات حقيقية في المجلد.
