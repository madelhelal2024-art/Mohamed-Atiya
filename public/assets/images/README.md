# مكتبة صور التطبيق

ضع الصور الجديدة داخل هذا المجلد، ثم استخدم مسارًا يبدأ بـ `/assets/images/` في بيانات التطبيق.

- صورة الأستاذ محمد عطية: `teacher-mohamed-atiya.webp` (نسخة محسّنة للعرض على الويب).
- الصور التعليمية المستقبلية: أنشئ مجلدًا فرعيًا لكل صف أو وحدة عند الحاجة، مثل `grade-6/`.
- استخدم أسماء ملفات إنجليزية صغيرة بشرطات `-`، مع وصف عربي مناسب داخل حقل `alt`.
- لا ترفع صور الطلاب أو مواد شخصية إلى المستودع العام دون إذن واضح.
- احتفظ بالصور الأصلية خارج مجلد النشر، وارفع النسخ المعتمدة للاستخدام فقط.
